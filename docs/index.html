Private Commit Heatmap

Your real work lives in private repos, so your GitHub graph looks empty. Export your daily commit counts, paste them here, and download a GitHub-style heatmap for your profile or portfolio.

View on GitHub

1. Export your commit dates

Run one of these where your repos are. It writes commit_days.txt with only dates and counts: no commit messages, file names or code.

macOS / Linux
curl -O https://raw.githubusercontent.com/vishwadeep-solves-conflicts/private-commit-heatmap/main/scripts/export_commit_days.sh
bash export_commit_days.sh "Your Name" 2024-01-01 ~/code/repo1 ~/code/repo2
Windows (PowerShell)
.\export_commit_days.ps1 -Author "Your Name" `
  -Since 2024-01-01 -Repos C:\code\repo1, C:\code\repo2

2. Paste the counts

Everything runs in this page. Nothing is uploaded.

3. Style it

{start} and {end} become month and year.

4. Preview and download

Show both themes on your GitHub profile README
